# Формат урока и типы карточек

Это всё, что умеет приложение. Генерировать можно только в этих рамках. Валидатор `npm run validate` (`scripts/validate-lessons.mjs`) проверяет формат, а типы в коде описаны в `src/types.ts`.

## Что умеет и чего не умеет приложение

- Показывает карточку. Пользователь отвечает **про себя**, тапает и видит ответ.
- На карточках с открытием ответа (`translate`, `chunk`, `transform`, `spot`, `form`) пользователь сам жмёт «Знаю» или «Ещё раз» (или свайпает вправо/влево). «Ещё раз» возвращает карточку через 3–5 карточек.
- `choice` — тап по одному из двух вариантов, проверка автоматическая.
- Кнопка «?» на карточке открывает шпаргалку правила (`rule`). Есть отдельный экран «Шпаргалка» со всеми правилами урока.
- Режимы: урок целиком (правила по порядку, внутри правила вперемешку), случайный микс N карточек из всех уроков, всё вперемешку.
- Прогресс между сессиями **не хранится**. Нет звука, ввода текста, картинок и распознавания речи.
- Строки показываются как обычный текст: markdown не работает. Выделить фрагмент можно только через `diff`. Пропуск в фразе обозначается `___`.

## Где лежит урок

```
content/<lang>/lessons/<id>/
  lesson.json   — урок (читает приложение)
  source.md     — расшифровка скриншотов (для перегенерации и добивания)
```

- `lang` — `en` или `sk`.
- `id` = имя папки: `lesson-01`, `lesson-02`… Двузначный номер, чтобы папки сортировались. Особые колоды: `life` (фразы из жизни), `demo` (пример, удалить).

## lesson.json

```json
{
  "id": "lesson-07",
  "lang": "en",
  "number": 7,
  "title": "Question tags",
  "date": "2026-10-07",
  "source": "Урок с учителем + Unit 6",
  "rules": [ ... ],
  "cards": [ ... ]
}
```

| Поле | Обязательно | Что это |
|---|---|---|
| `id` | да | Совпадает с папкой |
| `lang` | да | Совпадает с папкой языка |
| `number` | да | Порядок; в списке свежие сверху. `life` — 999, `demo` — 0 |
| `title` | да | Короткая тема на языке подсказок, 2–4 слова |
| `date` | нет | Дата урока, `YYYY-MM-DD` |
| `source` | нет | Откуда материал |

### Правило

```json
{
  "id": "tags-do",
  "title": "Теги с do / does / did",
  "summary": ["Нет вспомогательного глагола → do / does / did", "he, she, it → doesn't · прошлое → didn't"],
  "examples": [{ "target": "You like coffee, don't you?", "native": "Ты любишь кофе, да?" }]
}
```

- `id` — kebab-case, уникален в уроке.
- `summary` — 2–4 строки (максимум 6): формула и короткий пример, без теории.
- `examples` — 1–3 примера, лучше со слайда.
- Сложное правило делим на подправила. Исключения (*aren't I*, *shall we*) — отдельные правила.

### Карточка: общие поля

| Поле | Что это |
|---|---|
| `id` | Уникален в уроке. Префикс по типу: `t` translate, `w` chunk, `r` transform, `s` spot, `f` form, `c` choice + номер: `t01`. При дополнении продолжаем нумерацию |
| `type` | Один из шести типов ниже |
| `rule` | id правила из `rules`. У `chunk` и ложных друзей можно без правила |
| `prompt` | Что показывается |
| `answer` | Правильный ответ |
| `alt` | Другие верные варианты: полная форма вместо сокращения, синоним |
| `diff` | Фрагменты `answer`, которые подсвечиваются. Каждый должен буквально встречаться в `answer` |
| `note` | Одна строка «почему» или «проще» |
| `example` | Пример на изучаемом языке |
| `translation` | Перевод примера или фразы на язык подсказок |
| `tags` | `work`, `life`, `simple`, `false-friend`, `from-slide` |
| `verified` | `false` — карточка скрыта, пока пользователь не подтвердит (сомнительная форма) |

## Типы

### 1. `translate` — скажи на изучаемом языке

Основной тип. Подсказка на родном языке → ответ на изучаемом.

```json
{ "id": "t07", "type": "translate", "rule": "tags-have", "prompt": "Ты ведь уже смёржил, да?", "answer": "You've already merged it, haven't you?", "alt": ["You have already merged it, haven't you?"], "tags": ["work"] }
```

- 3–10 слов, одна целевая конструкция.
- Подсказка однозначна: в ней есть маркеры, которые определяют ответ (*уже, вчера, сейчас, обычно*).
- В SK `diff` обязателен: 1–2 места, где словацкий расходится с украинским.

### 2. `chunk` — словосочетание или готовая фраза

Значение на родном → словосочетание на изучаемом. Обратного направления нет: узнавать слова пользователь и так умеет.

```json
{ "id": "w01", "type": "chunk", "prompt": "действовать, принять меры", "answer": "take action", "example": "We need to take action now.", "translation": "Нам нужно действовать прямо сейчас." }
```

- Учим сочетания, а не голые слова: не *action*, а *take action*.
- `example` — короткая жизненная фраза, `translation` — её перевод.

### 3. `transform` — переделай фразу

Фраза на изучаемом языке и задание → новая фраза. Механика без нагрузки перевода.

```json
{ "id": "r02", "type": "transform", "rule": "tags-do", "prompt": "You fixed the bug.", "task": "→ добавь тег", "answer": "You fixed the bug, didn't you?" }
```

- `task` обязателен и короткий: «→ вопрос», «→ отрицание», «→ добавь тег», «→ в прошедшее», «→ она вместо я».

### 4. `spot` — найди ошибку

Фраза с **одной** типичной ошибкой носителя ru/uk → правильная фраза. Неверная фраза показывается красной и зачёркнутой.

```json
{ "id": "s01", "type": "spot", "rule": "tags-do", "prompt": "He don't like it, does he?", "answer": "He doesn't like it, does he?", "note": "He → doesn't." }
```

- Не больше 10% урока: частое чтение неверных форм может их закрепить.
- Ошибка реальная (интерференция), а не случайная опечатка.

### 5. `form` — поставь форму

Фраза с пропуском и начальной формой → нужная форма.

```json
{ "id": "f01", "type": "form", "rule": "past-som", "prompt": "Ty si to ___?", "lemma": "urobiť", "answer": "urobil", "full": "Ty si to urobil?", "vzor": "urobiť → urobil (ч. р.) · urobila (ж. р.)" }
```

- `prompt` содержит `___`. `lemma` — начальная форма с короткой подсказкой («vedieť, із запереченням»).
- `answer` — только форма; `full` — фраза целиком, содержит `answer`.
- `vzor` — образец: для SK взор или тип спряжения, для EN, например, «go → went».

### 6. `choice` — выбор из двух

Тап по одному из двух вариантов. Неверный вариант — всегда типичная ошибка, а не случайная форма.

```json
{ "id": "c02", "type": "choice", "rule": "tags-do", "prompt": "He works with us, ___?", "options": ["doesn't he", "isn't he"], "answer": "doesn't he", "translation": "Он же работает с нами, да?", "note": "Вспомогательного глагола нет → does." }
```

- `options` — ровно 2, `answer` среди них. Порядок не важен, приложение перемешивает.
- `prompt` — фраза с `___` или одно слово (ложный друг: `"čerstvý"` → `["свіжий", "черствий"]`).
- Для бинарных решений: артикль, вспомогательный глагол, долгота, написание.

## Пропорции по умолчанию

Подстраивай под содержание урока. Конкретные цифры для языков — в `en.md` и `sk.md`.

- 25–40 карточек на урок, 6–12 на правило.
- Каждое правило — хотя бы 2 типа карточек (например, `translate` и `choice`).
- 2–3 варианта на правило в жизненном контексте (`work` или `life`).

## Чеклист карточки

- [ ] Проверяет ровно одно правило, оно указано в `rule`
- [ ] Ответ однозначен; допустимые варианты в `alt`
- [ ] Ответ простой и разговорный, 3–10 слов, так скажет носитель
- [ ] Все слова, кроме целевых, знакомы (A1–A2 или из пройденных уроков)
- [ ] Подсказка на родном звучит естественно и не калькирует структуру изучаемого языка
- [ ] Не дублирует другую карточку с точностью до одного слова
- [ ] Пример со слайда сохранён дословно и помечен `from-slide`
